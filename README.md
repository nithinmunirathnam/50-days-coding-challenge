# 🚀 40 Days Data Analyst Challenge

Welcome to my **40 Days Data Analyst Challenge** repository!

This repository showcases my journey of completing **40 consecutive days of hands-on data analytics projects and coding challenges**. Each day focuses on solving real-world business problems using industry-standard tools and technologies to strengthen my analytical, technical, and problem-solving skills.

## 📌 Objective

The primary objective of this challenge was to:

- Develop strong data analysis and visualization skills.
- Gain practical experience with real-world datasets.
- Improve problem-solving using business scenarios.
- Build a professional portfolio demonstrating end-to-end analytics projects.
- Strengthen SQL, Python, Excel, and Power BI skills for Data Analyst roles.

## 🛠️ Tools & Technologies

Throughout this challenge, I worked with:

- 📊 Microsoft Excel

- 🗄️ SQL (PostgreSQL & MySQL)

## 📁 Repository Structure

Each day's challenge is organized in a separate folder.

Example:

```
Day 01 - Excel Data Analyst Challenge
Day 02 - Excel Analysis & Visualization
Day 03 - Nutrition & Growth Analysis
Day 04 - Loan Portfolio Dashboard
Day 05 - IT Help Desk Dashboard
...
Day 40 - Final SQL/Python Challenge
```

Each folder may include:

- 📄 Dataset(s)
- 📊 Excel Workbook
- 📈 Power BI Dashboard
- 🗄️ SQL Scripts
- 🐍 Python Programs
- 📷 Dashboard Screenshots
- 📝 README with problem statement, solution, and insights
