## 📌 Overview
This project is a beginner-friendly Python application that manages student marks and generates a simple student report. The program uses user-defined functions to calculate total marks, average marks, and grade based on student performance.

## 🎯 Objective
To practice Python programming concepts by building a Student Report System using:

- Functions
- Lists
- Input and Output
- Conditional Statements
- Arithmetic Operations
- Logical Thinking

## ❓ Questions

### 1. Create a Function `get_marks()`
- Take input for marks of 3 subjects
- Store the marks in a list
- Return the list

### 2. Create a Function `calculate_total(marks)`
- Accept the list of marks
- Calculate and return the total marks

### 3. Create a Function `calculate_average(total)`
- Accept the total marks
- Calculate and return the average marks

### 4. Create a Function `get_grade(avg)`
Return the grade based on the following conditions:

| Average Marks | Grade |
|---------------|-------|
| avg ≥ 90      | A     |
| avg ≥ 75      | B     |
| avg ≥ 50      | C     |
| avg < 50      | D     |

### 5. Main Program
- Call all functions
- Display:
  - Marks
  - Total Marks
  - Average Marks
  - Grade

## 🧾 Conclusion
This project helps beginners understand how functions are used to organize and simplify programs in Python. By developing this Student Report System, learners improve their understanding of lists, conditional statements, arithmetic operations, and modular programming concepts.
