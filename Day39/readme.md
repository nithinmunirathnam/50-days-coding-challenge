## 📌 Overview
This project focuses on analyzing a recent state election dataset using Microsoft Excel. The analysis includes vote share calculation, party performance evaluation, winner identification, gender analysis, age analysis, and dashboard creation using Excel tools such as Pivot Tables, formulas, charts, and conditional formatting.

The dataset contains synthetic election data with details like constituency, state, party, candidate name, votes received, total votes, gender, and age.

---

## 🎯 Objective
To perform election data analysis using Excel and gain practical experience in:

- Data Cleaning
- Excel Formulas
- Pivot Tables
- Data Visualization
- Dashboard Creation
- Analytical Thinking
- Real-world Data Analysis

---

## ❓ Questions

### 🔹 Task 1: Data Cleaning
- Check for duplicate records
- Format numeric columns properly
- Validate whether total votes are consistent constituency-wise

### 🔹 Task 2: Vote Share Calculation
Create a new column:

Vote % = (Votes / Total Votes) × 100

Use Excel formulas to calculate vote percentages for all candidates.

### 🔹 Task 3: Find Winners
Identify the winning candidate in each constituency using:
- MAX()
- IF()
- Pivot Tables

Display:
- Candidate Name
- Party
- Votes

### 🔹 Task 4: Party Performance
Analyze:
- Which party received the highest total votes statewide
- Which party won the highest number of constituencies

Use:
- Pivot Tables
- SUM aggregation

### 🔹 Task 5: Gender Analysis
Calculate total votes received by:
- Male candidates
- Female candidates

Identify whether any gender dominance exists.

### 🔹 Task 6: Age Analysis
Analyze:
- Average age of winning candidates
- Youngest candidate
- Oldest candidate

### 🔹 Task 7: Dashboard Creation
Create an Excel dashboard including:
- Bar Chart → Party vs Total Votes
- Pie Chart → Gender Vote Share
- Winners Table → Constituency-wise Winners

---

## 🚀 Advanced Level Tasks

### 🔹 Winning Margin Analysis
Create a column:

Winning Margin = Winner Votes − Runner-up Votes

### 🔹 Close Contest Highlighting
Highlight constituencies where winning margin is less than 5000 votes using Conditional Formatting.

### 🔹 Interactive Dashboard
Add slicers to Pivot Tables for:
- Party
- Gender
- Constituency

## 🌍 Real-World Insight
XYZ party performed strongly in urban constituencies because it secured higher vote shares in cities such as Bangalore South, Hyderabad, Chennai Central, and Visakhapatnam. Strong support among younger voters and female candidates, along with better urban campaign visibility, contributed to the party’s success.
